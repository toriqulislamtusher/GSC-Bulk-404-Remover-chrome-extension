# Privacy Policy for GSC Bulk CSV Remover

**Last Updated: October 16, 2026**

## 1. Introduction

GSC Bulk CSV Remover is a Chrome extension designed to help website owners, webmasters, and SEO professionals manage bulk temporary URL removal requests through Google Search Console.

This Privacy Policy explains how the extension accesses, processes, and stores information.

## 2. Information We Process

To perform its intended functionality, GSC Bulk CSV Remover processes:

- URLs manually entered or imported through CSV or TXT files.
- User-defined submission limits and delay settings.
- Temporary processing information, including submission progress and status.
- Information displayed in the Google Search Console interface that is necessary to perform user-requested removal operations.

The extension does not require users to create a separate account.

## 3. Local Data Storage

The extension uses Chrome's local storage functionality to maintain URL queues, workflow settings, and processing information.

This information is stored locally within the user's browser to support the extension's functionality.

The extension does not operate a separate developer-controlled server for storing user-submitted URLs.

## 4. Google Search Console Interaction

The extension interacts with Google Search Console to submit temporary URL removal requests initiated by the user.

URLs submitted through Google Search Console are processed by Google according to Google's applicable privacy policies and terms.

The extension is independently developed and is not affiliated with, endorsed by, or sponsored by Google.

## 5. Data Sharing

The extension does not sell user information or share it with advertisers or data brokers.

User-provided URLs are processed through Google Search Console when the user initiates removal requests.

The extension does not use user information for advertising, profiling, or unrelated purposes.

## 6. Permissions

The extension requests browser permissions necessary for its functionality, including:

- **activeTab:** To access the active tab when the user initiates the extension.
- **scripting:** To run the extension's packaged scripts within the relevant Google Search Console interface.
- **storage:** To maintain URL queues, settings, and processing information locally.
- **Host access:** To interact with Google Search Console pages required for URL removal operations.

These permissions are intended solely to support the extension's stated purpose.

## 7. Data Retention and User Control

Workflow information may remain in Chrome's local extension storage until it is cleared by the extension or removed through browser or extension data management.

Users can stop using the extension at any time and uninstall it through Chrome's extension management interface.

## 8. Security

The extension is designed to process information within the browser and the Google Search Console interface.

Users should submit removal requests only for websites and Search Console properties they are authorized to manage.

## 9. Children's Privacy

GSC Bulk CSV Remover is a productivity tool intended for website management and SEO-related tasks. It is not specifically directed toward children.

## 10. Changes to This Privacy Policy

This Privacy Policy may be updated to reflect changes in the extension's functionality, data practices, or applicable requirements.

Updates will be published on this page with a revised Last Updated date.
